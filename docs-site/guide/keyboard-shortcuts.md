# Keyboard Shortcuts

Reqit is built with a keyboard-first architecture. Every major action can be performed without reaching for your mouse.

---

## Global Application Shortcuts

| Action                           | Windows / Linux           | macOS                     |
| -------------------------------- | ------------------------- | ------------------------- |
| **Send Request**                 | <kbd>Ctrl+Enter</kbd>     | <kbd>Cmd+Enter</kbd>      |
| **Cancel In-Flight Request**     | <kbd>Escape</kbd>         | <kbd>Escape</kbd>         |
| **Save Request**                 | <kbd>Ctrl+S</kbd>         | <kbd>Cmd+S</kbd>          |
| **New Request**                  | <kbd>Ctrl+N</kbd>         | <kbd>Cmd+N</kbd>          |
| **New Collection**               | <kbd>Ctrl+Alt+N</kbd>     | <kbd>Cmd+Alt+N</kbd>      |
| **Command Palette**              | <kbd>Ctrl+K</kbd>         | <kbd>Cmd+K</kbd>          |
| **Import cURL**                  | <kbd>Ctrl+I</kbd>         | <kbd>Cmd+I</kbd>          |
| **Code Snippets Generator**      | <kbd>Ctrl+Alt+C</kbd>     | <kbd>Cmd+Alt+C</kbd>      |
| **Toggle Sidebar**               | <kbd>Ctrl+B</kbd>         | <kbd>Cmd+B</kbd>          |
| **Close Active Tab**             | <kbd>Ctrl+W</kbd>         | <kbd>Cmd+W</kbd>          |
| **Switch Tabs (Next)**           | <kbd>Ctrl+Tab</kbd>       | <kbd>Ctrl+Tab</kbd>       |
| **Switch Tabs (Previous)**       | <kbd>Ctrl+Shift+Tab</kbd> | <kbd>Ctrl+Shift+Tab</kbd> |
| **Keyboard Shortcuts Reference** | <kbd>Ctrl+/</kbd>         | <kbd>Cmd+/</kbd>          |
| **Open Settings**                | <kbd>Ctrl+,</kbd>         | <kbd>Cmd+,</kbd>          |

Reqit's editors are powered by CodeMirror 6 with full IDE editing capabilities:

| Action                          | Windows / Linux              | macOS                        |
| ------------------------------- | ---------------------------- | ---------------------------- |
| **Format JSON / GraphQL / XML** | <kbd>Shift+Alt+F</kbd>       | <kbd>Shift+Option+F</kbd>    |
| **Trigger Autocomplete**        | <kbd>Ctrl+Space</kbd>        | <kbd>Cmd+Space</kbd>         |
| **Variable Autocomplete**       | Type <kbd>&#123;&#123;</kbd> | Type <kbd>&#123;&#123;</kbd> |
| **Toggle Comment**              | <kbd>Ctrl+/</kbd>            | <kbd>Cmd+/</kbd>             |
| **Find / Replace**              | <kbd>Ctrl+F</kbd>            | <kbd>Cmd+F</kbd>             |
| **Duplicate Line**              | <kbd>Shift+Alt+Down</kbd>    | <kbd>Shift+Option+Down</kbd> |

## Customizing Shortcuts

You can inspect and customize your keybindings at any time:

1. Open **Settings** (<kbd>Ctrl+,</kbd>).
2. Select the **Shortcuts** tab.
3. Click any shortcut to record a new key combination.
4. Custom shortcuts are persisted locally in your application settings profile.
